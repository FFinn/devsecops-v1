# Отчёты анализа безопасности

В этом каталоге хранятся фактические отчёты, которые создаёт GitLab CI/CD:

1. `sast-report.json` — результат Semgrep;
2. `sca-report.json` — результат Trivy из успешного прогона;
3. `sca-report-red.json` — результат Trivy из заблокированного SCA-прогона;
4. `sbom.json` — перечень компонентов успешного прогона в формате CycloneDX;
5. `sbom-red-sca.json` — SBOM из заблокированного SCA-прогона;
6. `dast-report.html` — отчёт OWASP ZAP для просмотра человеком;
7. `dast-report.json` — тот же результат DAST в машиночитаемом формате.

Отчёты создаются инструментами автоматически и сохраняются как артефакты заданий CI/CD. Содержимое машинных отчётов вручную не редактируется.

Файлы обновлены после локальных прогонов `green`, `red-sast` и `red-sca`, поэтому они соответствуют текущей версии `.gitlab-ci.yml` и скриптов контрольных точек.
