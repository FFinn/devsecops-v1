# Generated security reports

This directory is the fixed output location for CI-generated security reports:

- `sast-report.json`
- `sca-report.json`
- `sbom.json`
- `dast-report.html`
- `dast-report.json`

The files are generated by GitLab CI and uploaded as job artifacts. They are
intentionally not replaced with hand-written sample reports.

For the final course submission, download the artifact from the green
`publish_security_bundle` job and copy the real generated files here if the
reviewer requires the reports to be committed to Git.
