# Отчёты анализа безопасности

В этом каталоге хранятся фактические отчёты, которые создаёт GitLab CI/CD:

1. `sast-report.json` — результат Semgrep;
2. `sca-report.json` — результат Trivy по известным уязвимостям зависимостей;
3. `sbom.json` — перечень компонентов в формате CycloneDX;
4. `dast-report.html` — отчёт OWASP ZAP для просмотра человеком;
5. `dast-report.json` — тот же результат DAST в машиночитаемом формате.

Отчёты создаются инструментами автоматически и сохраняются как артефакты заданий CI/CD. Содержимое машинных отчётов вручную не редактируется.

Перед итоговой сдачей нужно скачать артефакты последних локальных прогонов GitLab и обновить файлы в этом каталоге, чтобы они соответствовали текущей версии `.gitlab-ci.yml` и скриптов контрольных точек.
