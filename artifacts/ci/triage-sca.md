# Первичный разбор SCA

Файл отражает сохранённый успешный прогон, в котором Trivy не обнаружил известных уязвимостей в текущих версиях зависимостей.

| Компонент | CVE | Уровень | Установлена | Исправлена в | Стратегия | Обоснование |
|---|---|---|---|---|---|---|
| - | - | - | - | - | Monitor | В сохранённом зелёном отчёте Trivy известных уязвимостей не найдено. Для фактического разбора уязвимых зависимостей предусмотрен отдельный прогон `red-sca`. |

После запуска `SECURITY_DEMO_SCENARIO=red-sca` этот файл создаётся автоматически из настоящего `sca-report.json` и должен быть обновлён в репозитории вместе с отчётом.
